# Графовая база данных

Высокопроизводительная графовая база данных на C++ с собственным движком хранения, системой обработки запросов и комплексной системой тестирования.

## Обзор

База данных предоставляет мощный движок для работы с графовыми структурами с эффективными операциями над вершинами и рёбрами. Система спроектирована с модульной архитектурой, разделяющей управление хранением, обработку запросов и тестирование.

### Примечание
Проект закончен примерно на 10% и сейчас приостоновлен. Тестовая версия работает, но с некоторомы оговорками (касательно совместимости и многопоточности).

## Архитектура

### Движок хранения (Storage Engine)
**Самая важная и развитая часть системы** - низкоуровневый движок для эффективного хранения графовых данных:

- **Файловая организация** - специализированная структура файлов для вершин, рёбер и ключей
- **POD-структуры** - оптимизированные структуры данных для сериализации
- **Key-Value отображение** - эффективное преобразование ключей в идентификаторы
- **Двунаправленные рёбра** - поддержка прямых и обратных связей с взаимными ссылками
- **Типизированные данные** - поддержка `int`, `bool`, `string` и пользовательских структур

### Уровни абстракции:
1. **Файловая система** - низкоуровневые операции с файлами
2. **POD-структуры** - сериализованные данные (PayloadInfo, Array, KeylessMap)
3. **Адаптеры** - преобразование между структурами и файлами
4. **Менеджеры** - управление ключами, вершинами, рёбрами
5. **Движок** - высокоуровневый API для работы с графом

## Возможности

### Хранение данных
- **Гибкая схема** - поддержка пользовательских структур данных для вершин и рёбер
- **Эффективные ключи** - мапы с открытой адресацией на квадратичных числах
- **Двунаправленные связи** - автоматическое поддержание целостности рёбер
- **Сериализация** - оптимизированное хранение произвольных данных

### Операции
- **Добавление/удаление** вершин и рёбер
- **Поиск** вершин по ключам
- **Обход графа** - прямые и обратные рёбра
- **Целостность данных** - автоматическая валидация связей

## Структура проекта
```shell
GraphDB/
├── storage_engine/     # ⁂ Движок хранения (основная ветка)
│ ├── engine/           # Высокоуровневый API
│ ├── files/            # Файловые адаптеры и сериализация
│ ├── manager/          # Управление базами данных
│ └── utils/            # Вспомогательные утилиты
├── querry_engine/      # Система обработки запросов
│ ├── parser/           # Парсер запросов
│ ├── handler/          # Обработчики запросов
│ └── graph/            # Графовые операции
└── tests/              # Комплексное тестирование
├── storage_engine/     # Тесты движка хранения
├── manager/            # Тесты менеджера
└── POD/                # Тесты структур данных
```
